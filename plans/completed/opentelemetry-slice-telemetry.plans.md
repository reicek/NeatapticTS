## Goal

**DELIVERABLE.** A repo-owned, versioned, per-slice telemetry ledger for the NeatapticTS agent workflow: how long a slice took, how many tool **executions completed** inside its dispatch window, and how many **context tokens were delivered** to it — recorded per slice, forward-only, with an unavailable counter reported as `null` plus a machine-stable reason and **never** as `0`.

**THE TWO LAYERS, AND THE BOUNDARY BETWEEN THEM.**

| layer | owner | failure mode | what it owns |
| --- | --- | --- | --- |
| Layer A — the OpenTelemetry signal layer | the local SDK and the three local JSONL exporters (traces, metrics, logs) | **fail-open** — a disabled, broken or uninstalled layer never excuses a missing measurement | the sanitized, local-only signal |
| Layer B — the repo-owned per-slice YAML ledger | `scripts/telemetry/write-slice-ledger.mjs` and `scripts/telemetry/ledger-state.mjs` | **fail-closed** — a new `[DONE]` transition without a valid ledger is refused | the measured, persisted, per-slice record |

**THE TWO LOAD-BOUNDARY CLAUSES.** (1) **THE TOOL SIGNAL COUNTS COMPLETED EXECUTIONS, NEVER ISSUED CALLS** — a call denied before execution never completes and is therefore not counted. (2) **THE TOKEN SIGNAL COUNTS CONTEXT TOKENS DELIVERED, NEVER MODEL TOKEN CONSUMPTION** — the model-consumption fields stay `null` with a reason until the runtime exposes them.

**THE FOURTEEN TOP-LEVEL CRITERIA.** `AC-001` the two layers are independent and layer A is fail-open; `AC-002` the ledger is versioned, keyed, idempotent, one block per slice and forward-only; `AC-003` no timestamps, no dates and no personal data in any persisted artefact; `AC-004` the sources are evidenced, an unavailable counter is `null` and never zero, success and failure are counted separately, and no payload is persisted; `AC-005` the attribution contract is demonstrated by an executable probe before any dependent implementation; `AC-006` the layer-A and layer-B states are independent, locally auto-repaired and safely recovered, and the writer owns `--recover`; `AC-007` the DONE closure is fail-closed and is not weakened by a warn-only layer A; `AC-008` incremental extraction with a prefix guard, a date-free cursor, atomic derived-state writes, statistics and a measured cost; `AC-009` a deterministic flush and shutdown per entry point that never throws, and layer A never measures a slice duration; `AC-010` the boundary is distinct, the ruled set is consumer-installable, single-identity and two-floored; `AC-011` the dispatch-time producer and the tool-execution attribution boundary are owned, implemented and enforced; `AC-012` layer B owns the production of every per-slice measurement and layer A may only consume it; `AC-013` the attribution probe is executable and gates its dependents; `AC-014` the compression contract itself.

### M-1 — every usable telemetry signal is logged from the next slice onward; an unusable signal is `null` + a reason, never `0`

- **The obligation.** From `OT-S1-3` onward, **EVERY slice in this tracker is ledger-producing.** A slice closes with a recorded measurement for **each** signal this tracker defines: the duration, `usage.context_tokens_delivered`, `usage.tool_executions` and the model-consumption fields.
- **A usable signal carries its real value.** If the signal was measured, the persisted field carries that measured value and the record marks it available.
- **AN UNUSABLE SIGNAL IS `null` + A REASON — NEVER `0`, NEVER A GUESS, NEVER AN OMISSION.** A signal that could not be attributed, a source that is not yet demonstrated, an observer that was not loaded, a measurement that was interrupted: the counter is `null`, the record says `available: false`, and it carries the concrete reason. **A `0` IS A LEGITIMATE VALUE ONLY WHEN THE COUNT WAS GENUINELY ZERO** — for example, no tool execution completed inside the open dispatch window because the slice performed none. **A `0` IS NEVER A SUBSTITUTE FOR "NOT MEASURED".**
- **THE PRIVACY RULES ARE UNCHANGED BY THIS MANDATE.** No exact start/end timestamp, no calendar date, no clock time and no wall-clock instant in any persisted artefact; no PII, no absolute user paths, no git remotes, no secrets, no tool arguments, no tool results, no file contents, no prompts and no diffs; the runtime metadata set stays exactly Node version, duration, validation results, heap usage and RSS usage; no platform / architecture / CPU-count / total-memory fingerprinting; no `neat.acceleration.*` timing metrics. **A REASON WRITTEN UNDER THIS MANDATE IS A SHORT MACHINE-STABLE TOKEN** — for example `observer_not_loaded`, `no_open_dispatch_record`, `source_not_demonstrated` — **AND NEVER A FREE-TEXT MESSAGE THAT COULD CARRY A PATH, AN ARGUMENT, A RESULT, A TIMESTAMP OR A NAME.** The allow-list sanitizer plus the independent deny-list second pass still apply to every artefact, and the forbidden-key and forbidden-value sweep still runs over **every** artefact the lane writes, with no exclusion.
- **THE FORWARD-ONLY RULE IS UNCHANGED BY THIS MANDATE.** The ledger is **forward-only**: there is **NO backfill** of the pre-existing `[DONE]` slices, and no slice that predates this mandate is retro-demanded a measurement it never took. The **measured** pre-existing `[DONE]` set — not the stated count — stays the authoritative one for the forward-only boundary.
- **HONEST STAGING OF ENFORCEMENT.** This mandate binds the **authoring duty** from `OT-S1-3` onward, and it binds the **fail-closed duty** only from the slice in which the DONE writer and the DONE gate land. **THE FAIL-CLOSED DONE GATE REFUSES A NEW `[DONE]` TRANSITION THAT HAS NO VALID LEDGER, AND THAT REFUSAL BINDS ONLY FROM THE SLICE THAT LANDS THE WRITER AND THE GATE.** Before that point a slice records what it can measure and writes the rest as `measurement_state: 'UNAVAILABLE'` with a reason through the writer's `--recover` mode. **A SLICE THAT CLOSED BEFORE THE WRITER LANDED IS NOT RETRO-FAILED AND IS NOT RETRO-DEMANDED A MEASUREMENT.** The mandate never weakens the fail-closed rule — it declares honestly when that rule starts binding, and from then on it binds in full.
- **PINNED BY** `AC-002` (forward-only, one block per slice, idempotent), `AC-004` (evidenced sources; unavailable is `null`, never zero), `AC-006` (the layer-A and layer-B states are independent; the writer owns `--recover`), `AC-007` (the DONE closure is fail-closed) and `AC-012` (layer B owns the production of every per-slice measurement).

### M-2 — a hook or a setting is enabled in the slice that lands it, and the lane stops for a CLI reset when the change is not live

- **ENABLE AS YOU LAND.** A hook entry, a manifest registration or a local setting is **enabled in the SAME slice that lands it** — never deferred to the lane close, never deferred to a later phase. **A CHANGE THAT IS WRITTEN BUT NOT ENABLED IS AN INCOMPLETE SLICE.** A hook that is written and registered but never enabled is exactly as incomplete as a hook that was never written.
- **THE LOAD BOUNDARY IS REAL AND IS NOT NEGOTIABLE.** Repository hooks are loaded by the CLI at **startup** or after a **`/cd`** into the repository, so **a manifest or setting change is NOT live in the session that wrote it.** The lane therefore **STOPS** at that point.
- **THE STOP IS AN ASK FOR A CLI RESET — NOT A BLOCKER AND NOT A FIX-LOOP ITERATION.** The lane asks the operator to reset the CLI — a fresh session, or the documented reload boundary — and records **exactly what landed, what is not yet live, and what must be re-measured after the reset.** **A CLI-RESET STOP IS NOT A BLOCKER:** it does not open a fix loop, it does not consume a convergence iteration and it does not flip the slice to a failed state. It is a **scheduled pause at a known boundary.**
- **THE LANE MUST NOT ASSERT, MEASURE OR PROVE THE BEHAVIOUR OF AN UNLOADED HOOK.** Until the reset has happened, the lane records that the change is **pending activation**; it does **NOT** claim the observer fired, does **NOT** count executions it could not have observed, and does **NOT** record a proof it did not take. **THE PROOF OF A HOOK IS TAKEN IN A FRESH SESSION** (`AC-011-E`) — a transcript taken in the session that wrote the manifest measures a hook that was never loaded, and it is not accepted.
- **THE SLICE STAYS OPEN UNTIL THE POST-RESET MEASUREMENT EXISTS.** A slice that landed an activation-boundary change stays `[WIP]` until the measurement taken after the reset exists and is recorded. **THE OBLIGATION IS NOT DISCHARGED BY WRITING THE FILE.**
- **THE LOCAL SETTINGS ARE NOT A TRACKED FILE.** The local telemetry settings live under `logs/telemetry/`, which is git-ignored and auto-created and auto-repaired by the ensure command; **THE ENSURE COMMAND REPORTS THE ABSENCE OF A TRACKED HOOK AND NEVER REWRITES A TRACKED FILE AT RUNTIME.** A tracked registration is changed in the slice that owns it, by an edit, and is then activated by the reset boundary above.
- **PINNED BY** `AC-011` (the observer is registered as a tracked hook entry and the honest scope of the counter is reported) and `AC-011-E` (the load boundary).
