WebGPU Parallel Throughput Benchmark

Runs in a single visible, foreground browser window and emulates six parallel agents. Each agent owns its own Network.createMLP() instance with its own GPU buffers, and all agents share one WebGPU device. The benchmark measures per-agent latency, aggregate throughput across all agents, and GPU contention overhead compared to a single-agent baseline. The result is a downloadable JSON artifact.
